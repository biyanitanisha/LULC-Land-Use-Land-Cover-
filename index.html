Overview

Project Overview

This project demonstrates how cloud-based geospatial processing can be used to prepare and communicate a land-cover classification for a rapidly changing metropolitan region.

Using Sentinel-2 satellite imagery processed in Google Earth Engine, this interactive explorer distinguishes major surface-cover categories across Hyderabad to analyze urban expansion and environmental patterns.

Technical Details

Methodology & Interpretation

Classification Method: Built using a Sentinel-2 surface reflectance composite averaged over Jan–Jun 2025. A CART decision-tree classifier (ee.Classifier.smileCart) was trained on digitized reference points across 4 distinct classes using RGB surface reflectance bands at 10m resolution.

Interpretation: Built-up land dominates the classified extent (~68%), reflecting Hyderabad's rapid IT and industrial corridor growth. Green spaces (~23%) account for remaining urban tree canopy and agricultural pockets. Waterbodies (~7.7%) capture key historic reservoirs such as Hussain Sagar.
